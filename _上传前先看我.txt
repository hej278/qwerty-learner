目录说明
--------
index.html        网站首页
vercel.json       给 Vercel 的配置（保证子页面刷新不报 404）
assets/           程序主体（编译好的 JavaScript 和 CSS）

dicts/            词库
  ├─ my_spell.json        ← 你的错词本（178 条）
  ├─ my_phrase.json       ← 你的短语本（78 条）
  └─ 另外 9 个            ← 内置英语词库（托福 / 考研 / 四六级 / GRE / 雅思）

sounds/           按键音效（含 14 种机械键盘音色）
favicon-*.png     浏览器标签页图标
manifest.json     手机"添加到主屏幕"用的配置
robots.txt        搜索引擎说明
og-image.png      分享到社交平台时的预览图
_上传前先看我.txt  本文件


以后怎么换词表
--------------
1. 把新词表交给 AI，转成 JSON（格式：一串 {"name":"词","trans":["释义"]}）
2. 在 GitHub 上打开 dicts/ 文件夹 → Add file → Upload files → 拖入同名文件覆盖
3. 点 Commit changes，约 1 分钟后生效
4. 如果【词数变了】，还需要一起换 assets/index-ced097e3.js
   （因为程序里记着"这个词库有多少个词"，用来算章节）

想【新增】一个词库（而不是替换）：需要改 assets/index-ced097e3.js 里的注册表，
交给 AI 做，不要自己改。
